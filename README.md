## Cómo ejecutar localmente

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar el servidor:
   ```bash
   npm start
   ```

3. Abrir en el navegador:
   http://localhost:3000

## Pruebas de la API
